# Dataset C paper materials

This archive contains copies of existing project outputs. No experiments were run and no result files were edited to prepare it.

## Folders

- `reports/` — consolidated Dataset C research report, final optimization report, advanced execution report, and methodology audit.
- `tables/final_research/` — earlier Phase 2/Phase 3 master comparison and repeated-CV tables.
- `tables/final_optimization/` — later nested-CV summary, outer-fold results, candidate-selection results, and selected-scope holdout metrics.
- `tables/` — model comparison, nested-CV summary and selected features from the existing reproducibility run; filenames mark these as reproducibility-run exports.
- `dataset_summary/` — existing dataset summary CSV.
- `feature_selection/` — final selected features plus selector fold support, frequency and importance tables.
- `confusion_matrices/` — per-scope confusion matrix CSV and PNG files from the existing reproducibility run.
- `figures/final_research/` — complete final-research figure set, including figure captions.
- `figures/final_optimization/` — later optimization figure set, including nested-CV, ROC, PR, confusion-matrix and feature-importance figures.
- `figures/reproducibility_run/` — existing ROC, precision-recall and model-comparison plots.

The research report preserves earlier experiment stages; the optimization report documents the later nested-CV analysis. These are kept in separate folders/tables to retain their stage labels and provenance.
